# 03. Move

Status: specification. Requirement prefix `REF-MOV`. Java in full depth, Kotlin where the Kotlin
plugin defines its own behavior. Framework rules (conflicts dialog, preview, undo) are in
`01-framework.md`. Executable cases: `cases/03-move.cases.md`.

ic: `platform/lang-impl/src/com/intellij/refactoring/move/{MoveHandler,moveFilesOrDirectories/*}.java`,
`java/java-impl-refactorings/src/com/intellij/refactoring/move/**` (`moveClassesOrPackages/*`, `moveInner/*`,
`moveMembers/*`, `moveInstanceMethod/*`), `platform/refactoring/resources/messages/RefactoringBundle.properties`,
`java/openapi/resources/messages/{JavaRefactoringBundle,JavaBundle}.properties`,
`plugins/kotlin/refactorings/**/move/**`, `plugins/kotlin/base/resources/resources-en/messages/KotlinBundle.properties`,
`java/java-impl/src/com/intellij/refactoring/JavaRefactoringSettings.java`.

Move (`F6`) relocates classes, packages, directories, files, static members, inner classes and
instance methods, and updates every reference, import, package declaration and (optionally)
non-code occurrence.

## 2. Moving classes and packages (Java)

Dialog `Move` (modal; `Refactor`, `Preview`, `Cancel`). Top to bottom:

1. Label: for one element `Move {kind} {qualified name}` (for example `Move class p.Foo`); for several `Move specified classes` / `Move specified packages`.
2. When moving classes (not packages) a radio group: `To package` (selected) / `Make inner class of`
   (`Make inner class of` is preselected instead when invoked with a target class container).
3. `To package:` combo (editable package name with a browse button `Choose Destination Package`),
   prefilled with the package of the target container if any, else the current package.
4. `Destination directory:`-style combo shown when the module has several source roots: entries
   `Leave in same source root` and each suitable root; checkbox `Move to another source folder`
   (`Move to another source folder`, shown when more than one root exists).
5. Checkboxes `Search in comments and strings`, `Search for text occurrences`; for enums `Move as enum constants if possible` where applicable.
6. When `Make inner class of` is selected, the destination class combo (class chooser).

|---|---|---|---|

## 3. Moving static members, instance methods, inner classes (Java)

### 3.1 Move Members

Dialog `Move Static Members` (modal). Content: label `Move members from:` with the source class name;
label `To (fully qualified name):` with an editable class combo (browse button
`Choose Destination Class`, remembered recents); a table with border title `Members to be moved (static only)`
(checkbox column and the members of the class that can be moved: static fields, static
methods, static nested classes), the initially selected rows are the elements the action was invoked on; a `Visibility` panel
with radio buttons `As is` (default), `Escalate`, `Private`, `Package local`, `Protected`, `Public`;
checkbox `Move as enum constants if possible` (shown when static final fields of the enum-like
shape are selected; default on); `Preview` and `Refactor`.

| ID | Pri | Requirement | Acceptance |
|---|---|---|---|
| REF-MOV-030 | MUST | Invocation errors (dialog titled `Move Static Members`): non-static field `Field {0} is not static.\nMove Static Members refactoring is supported for static members only.` ({0} is the field formatted as `name: type`), non-static method `Method {0} is not static.\nMove Static Members refactoring is supported for static members only.`, constructor `Move Static Members refactoring cannot be applied to constructors`, non-static inner class `Inner class {0} is not static.\nMove Static Members refactoring is supported for static members only.`, members from different classes: `Cannot perform refactoring.\nMembers to be moved should belong to the same class`. | Case REF-MOV-030 case 1. |
