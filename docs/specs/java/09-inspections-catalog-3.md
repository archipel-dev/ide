# 09. Java inspections catalog, part 3

Status: specification, clean-room. Written from the IntelliJ IDEA Community sources in our own words. Message
templates, option labels and fix names are quoted from the message bundles (short user-visible strings). Source
paths are cited as `ic: <path>`. No code is reproduced.

Part 3 covers the inventory file `inventory/inspections-java-3.md`: the Java groups Code style issues (80),
Compiler issues (4) and Concurrency annotation issues (6). How to read the tables, the priority rule and the case
conventions are the same as in `09-inspections-catalog-1.md` (section 9.1) and in `cases/README.md`. Rows that only
point to an existing requirement (`JAVA-INS-*`) are listed under "Covered by existing specs".

Most Code style inspections have the level Information: the editor shows no marker and the fix is offered through
Alt+Enter (their cases press Alt+Enter at the caret). The "cleanup-eligible" ones take part in
*Code | Code Cleanup* with the safe fix applied file-wide.

Primary sources: `ic: java/java-backend/resources/META-INF/InspectionGadgets.xml` and
`ic: java/java-backend/resources/META-INF/Inspections.xml` (registration), message bundles
`InspectionGadgetsBundle.properties`, `JavaAnalysisBundle.properties`, `JavaBundle.properties`,
`JavaErrorBundle.properties`, the gadget classes under `ic: java/java-analysis-impl/src/com/siyeh/ig/` and
`ic: java/java-impl/src/com/siyeh/ig/`, `ic: java/java-impl-inspections/`.
