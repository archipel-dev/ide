# 09-8. Java inspections catalog, part 8 (security, serialization, test frameworks, threading)

Status: specification, clean-room. Written from the IntelliJ IDEA Community sources in our own words. Message
templates, option labels and quick-fix names are quoted from the message bundles (short user-visible strings).
Source paths are cited as `ic: <path>`. No code is reproduced. Inventory: `docs/specs/inventory/inspections-java-8.md`.
Requirement ID prefix: JAVA-ICC. Conventions (columns, priorities, ranges, case format) are those of
`docs/specs/java/09-inspections-catalog-7.md` section 0; framework: `docs/specs/codeinsight/03-inspections.md`.
Executable cases: `docs/specs/java/cases/09-inspections-8.cases.md`.

Shared quick-fix names used below (from the common fix helpers): `Make '{0}' static final`, `Make method '{0}()' 'final'`,
`Remove '{0}' modifier`, `Make '{0}'` (modifier change, e.g. `Make 'private'`), `Remove unnecessary '{0}'` (deletes a statement),
`Replace method call with '{0}'`, `Add 'serialVersionUID' field`.

## 1. Java / Security (16)

All security inspections are disabled by default (they are audit helpers) and use the SHOULD priority. The five "non-constant string"
inspections share one option `Consider 'static final' fields constant` (off): a call argument is "constant" when it is a compile-time
constant; with the option, a reference to a `static final` field also counts as constant regardless of how the field is initialised.
