# 09-9. Java inspections catalog, part 9 (verbose or redundant code, visibility, toString, language-level migration aids, Lombok and Kotlin interop)

Status: specification, clean-room. Written from the IntelliJ IDEA Community sources in our own words. Message
templates, option labels and quick-fix names are quoted from the message bundles (short user-visible strings).
Source paths are cited as `ic: <path>`. No code is reproduced. Inventory: `docs/specs/inventory/inspections-java-9.md`.
Requirement ID prefix: JAVA-ICC. Conventions (columns, priorities, ranges, case format) are those of
`docs/specs/java/09-inspections-catalog-7.md` section 0; framework: `docs/specs/codeinsight/03-inspections.md`.
Executable cases: `docs/specs/java/cases/09-inspections-9.cases.md`. Rows that say "see JAVA-INS-nnn" are already specified there.

"INFORMATION" level means no marker in the editor: the fix is offered as an Alt+Enter intention only when the caret is on the range.
